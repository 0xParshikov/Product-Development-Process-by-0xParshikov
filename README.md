# Производственный процесс 2.4.3

Правила соло-разработки с AI-агентами: роли, постановка задач, проверки,
выпуск и работа над ошибками. Используются в исследовательском проекте 0xExqui.OS.

## Скачать

[Скачать ZIP версии 2.4.3](https://github.com/0xParshikov/Product-Development-Process-by-0xParshikov/archive/refs/tags/v2.4.3.zip)
или [открыть файлы выпуска](https://github.com/0xParshikov/Product-Development-Process-by-0xParshikov/tree/v2.4.3).

## Файлы

- [AGENTS.md](AGENTS.md) — правила взаимодействия и ответственность ролей.
- [ENGINEERING.md](ENGINEERING.md) — типы задач, фазы, критерии перехода и метрики.
- [manifest.json](manifest.json) — версия, происхождение и контрольные суммы файлов.

## Использование

1. Прочитайте AGENTS.md и ENGINEERING.md вместе.
2. Задайте корень проекта с правилами вместо `<PLATFORM_ROOT>`.
3. Подготовьте документы своего проекта, перечисленные в разделе «Документы» ENGINEERING.md.
4. Подключите инструкции к своему AI-инструменту; используемые навыки Superpowers устанавливаются отдельно.

Архитектура, сеть, рабочие реестры, требования к тексту и интерфейсам относятся
к конкретному проекту и в этот комплект не входят. Проверки и права доступа
нужно соотнести со своей средой. Готовность процесса для полноценной команды не заявляется.

Публичная копия сохраняет правила версии 2.4.3. Локальный путь заменён на
`<PLATFORM_ROOT>`, ссылки на непубликуемые проектные документы оставлены названиями файлов.
Это минимальная публикация инструкций; подробное описание подхода будет подготовлено отдельно.
