# Product Development Process by 0xParshikov

Производственный процесс разработки 0xExqui.OS. Текущая принятая версия — 2.3.1.

- [AGENTS.md](AGENTS.md): взаимодействие и роли команды.
- [ENGINEERING.md](ENGINEERING.md): фазы разработки, проверки и решения владельца.

Это самостоятельный проект развития правил, A/B-пилотов и разбора качества процесса.
Публичный GitHub-репозиторий `0xParshikov/Product-Development-Process-by-0xParshikov`: README,
описание подхода, принятые версии и обезличенные выводы.
Этот выпуск содержит принятые правила версии 2.3.1.

Изменение правил и принятие новой версии согласуются владельцем. Остальные проекты
используют закреплённую версию; изменения здесь не обновляют их автоматически.
Инфраструктура и размещение приложений относятся к проекту Платформы.

Рабочие реестры рисков и проблем остаются едиными у Платформы. В публичный проект
не копируются личные данные, закрытые адреса/доступы, рабочие журналы и ключи.
Следующий результат — выбрать первый согласованный пилот или изменение процесса.
